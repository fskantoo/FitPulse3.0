Come scaricare l’IPA di FitPulse su Windows

GitHub Actions crea il file IPA online. Segui questi passaggi dal PC Windows: non serve un Mac.

Scarica il progetto FitPulse

Se hai già il repository FitPulse

  1. Estrai la versione aggiornata di FitPulse-iOS-aggiornato.zip.
  2. Apri la cartella locale del tuo repository con GitHub Desktop e copia dentro tutto il contenuto aggiornato della cartella estratta, inclusi FitPulse, AppAssets.xcassets e .github. Accetta la sostituzione dei file.
  3. In GitHub Desktop scrivi un riepilogo, premi Commit to main e poi Push origin. Il push fa partire la nuova compilazione.
  4. Segui le istruzioni nella sezione “Scaricare il file IPA sul PC” più sotto. La nuova app include le modifiche e l’icona aggiornata.

Prima di iniziare

  • Ti servono un account GitHub e il progetto FitPulse.
  • Se non hai ancora caricato il progetto su GitHub, scarica lo ZIP qui sopra e segui la sezione “Caricare il progetto” più sotto.
  • Se il progetto è già su GitHub, vai direttamente a “Avviare la compilazione”.

Attenzione: lo ZIP del progetto non è l’IPA. Non cambiare il nome o l’estensione. L’IPA apparirà come artifact solo dopo una compilazione completata con successo.

1. Caricare il progetto su GitHub (solo la prima volta)

  1. Scarica FitPulse-iOS-aggiornato.zip e fai clic destro sul file → Estrai tutto.
  2. Su GitHub.com, accedi e crea un repository, ad esempio FitPulse-iOS. Seleziona Private.
  3. Installa e apri GitHub Desktop. Accedi con GitHub e scegli File → Clone repository. Seleziona il repository appena creato.
  4. Apri la cartella locale del repository. Copia al suo interno tutti i file e le cartelle estratti dallo ZIP, non solo la cartella esterna.
  5. Assicurati che nella cartella del repository esistano .github\workflows\build-ios-ipa.yml e FitPulse.xcodeproj. Se non vedi .github, in Esplora file attiva Visualizza → Mostra → Elementi nascosti.
  6. In GitHub Desktop inserisci un riepilogo, per esempio Add FitPulse iOS project, premi Commit to main e poi Push origin.

2. Avviare la compilazione dell’IPA

  1. Apri il repository su GitHub.com e fai clic sulla scheda Actions.
  2. Se GitHub mostra un avviso per abilitare Actions o i workflow, premi il pulsante di conferma.
  3. Nella colonna a sinistra seleziona Build FitPulse IPA.
  4. Premi Run workflow, lascia selezionato il branch main e conferma con il pulsante verde Run workflow.
  5. La nuova esecuzione comparirà nell’elenco. Fai clic sulla riga più recente per aprirla.
  6. Attendi il completamento: deve apparire il segno verde di successo. Se vedi una X rossa, la compilazione non è riuscita e l’IPA non è disponibile.

3. Scaricare il file IPA sul PC

  1. Nella pagina dell’esecuzione completata, scorri verso il basso fino alla sezione Artifacts.
  2. Fai clic su FitPulse-unsigned-ipa. Il browser scaricherà un archivio ZIP.
  3. Apri la cartella Download di Windows. Fai clic destro sullo ZIP scaricato → Estrai tutto.
  4. Apri la cartella estratta. Il file che ti serve si chiama FitPulse-unsigned.ipa. Ora si trova sul tuo PC.

Se non trovi “Artifacts”, controlla che la run sia terminata con successo e che la pagina sia quella della run, non solo la lista delle esecuzioni.

Attivare il Coach IA e lo scanner del piatto

  1. Apri Google AI Studio e crea una tua chiave API Gemini.
  2. Apri FitPulse su iPhone e premi Coach IA oppure Scan AI, poi scegli Configura la chiave IA.
  3. Incolla la chiave e salvala sul dispositivo. Non inserirla nel repository GitHub e non condividerla con altre persone.
  4. Per lo scanner, scatta o carica una foto JPG, PNG o WebP e premi Analizza con IA. Se una foto HEIC non si apre, convertila in JPG o usa “Più compatibile” nelle impostazioni della fotocamera iPhone.

La chiave è salvata solo sul dispositivo, ma domande, obiettivi FitPulse e foto vengono inviati a Google Gemini. Controlla limiti, condizioni ed eventuali costi del tuo account AI Studio. Le risposte e le stime del piatto sono indicative e non sostituiscono un professionista sanitario.

Se “Build FitPulse IPA” non compare

  1. Controlla su GitHub che il file sia esattamente in .github/workflows/build-ios-ipa.yml nella radice del repository.
  2. Verifica di aver caricato e inviato i file con Push origin.
  3. Torna ad Actions e aggiorna la pagina. Se GitHub chiede di abilitare i workflow, conferma.
  4. In alternativa, un nuovo push sul branch main avvia automaticamente la compilazione.

Se la build dice “configuration ... is not supported”

  1. Nel repository GitHub apri .github/workflows/build-ios-ipa.yml.
  2. Premi la matita per modificare e trova la riga runs-on: macos-14.
  3. Sostituiscila con runs-on: macos-15, poi premi Commit changes.
  4. Apri Actions: il commit avvia una nuova compilazione. Apri la run più recente e attendi il segno verde prima di scaricare l'artifact.

Dopo il download

L’IPA scaricato non è ancora firmato per il tuo iPhone. Per installarlo, apri Sideloadly su Windows, collega l’iPhone, seleziona il file FitPulse-unsigned.ipa e premi Start. Scarica Sideloadly solo dal sito ufficiale.

Con un Apple ID gratuito, la firma in genere scade dopo circa 7 giorni e l’installazione va rinnovata. Non condividere password o codici di verifica Apple.
